구글시트 연결

처음 설정하는 방법 팀에서 한 명만
  1. 1
    외부 FAQ용 구글시트를 새로 만들어요.내부용 업무 FAQ 시트와는 다른 새 시트예요. 시트를 만든 계정이 데이터의 주인이 돼요.
  2. 2
    시트 메뉴에서 확장 프로그램 → Apps Script를 열고, 기본으로 있는 코드를 모두 지운 뒤 아래 코드를 붙여넣어요.
  1. 3
    코드 맨 위 두 가지 키를 서로 다른 값으로 바꾸고 저장(💾)해요.ADMIN_KEY: 관리페이지용(추가·수정·삭제). 팀 안에서만 공유해요. 예: kyobo-ext-admin-7q2m
    VIEW_KEY: 노출용 페이지용(보기만). 외부에 전달하는 키예요. 예: kyobo-faq-2026
  2. 4
    위쪽 함수 목록에서 setup을 고르고 [실행]을 눌러요. 권한 검토 창이 뜨면 계정을 고르고, ‘확인되지 않은 앱’ 화면에서 고급 → (프로젝트 이름)(으)로 이동 → 허용을 눌러요.시트에 ‘FAQ’ 탭이 생기면 성공이에요. 내가 만든 코드라서 나오는 안내 화면이에요.
  3. 5
    오른쪽 위 [배포] → [새 배포] → 유형 선택(톱니바퀴)에서 웹 앱을 고르고, 실행 사용자 ‘나’, 액세스 권한 ‘모든 사용자’로 두고 [배포]해요.
  4. 6
    나온 웹 앱 URL(…/exec로 끝나요)을 위 주소 칸에 붙여넣고, ADMIN_KEY와 이름을 입력한 뒤 [연결하기]를 눌러요.
  5. 7
    연결되면 [노출용 페이지 만들기]를 눌러요. 웹 앱 주소가 미리 들어간 노출용 페이지 파일이 내려받아져요.외부에는 이 파일과 VIEW_KEY만 전달하면 돼요. 받은 사람은 접속 키만 입력하면 바로 볼 수 있어요.
알아두면 좋아요
· 코드를 고친 뒤에는 [배포] → [배포 관리] → 연필 아이콘 → 버전 ‘새 버전’ → [배포]를 해야 반영돼요. 주소는 그대로 유지돼요.
· VIEW_KEY로는 보기만 할 수 있고, 작성자 이름도 보이지 않아요. ADMIN_KEY는 외부에 전달하지 마세요.
· 키를 바꾸고 싶으면 코드에서 값을 바꾼 뒤 새 버전으로 배포하면 돼요. 노출용 페이지 파일은 다시 만들 필요 없이 새 VIEW_KEY만 알려주면 돼요.
· 회사 구글 계정에서는 ‘모든 사용자’ 옵션이 막혀 있을 수 있어요. 이럴 땐 개인 계정 시트를 써 주세요.
· 시트에서 직접 질문·답변을 입력하거나 고쳐도 돼요. 다음 새로고침 때 도구에 반영돼요.

사용방법

처음 연결하기

외부 FAQ는 내부용 업무 FAQ와 다른 구글시트에 저장돼요. 처음 한 번만 연결하면 다음부터는 자동으로 연결돼요.

  1. 1
    담당자에게 웹 앱 주소와 관리자 접속 키를 받아요.메신저로 받은 연결 정보 안내문에 두 가지가 모두 들어 있어요. 외부에 전달하는 보기 전용 키로는 관리페이지를 쓸 수 없어요.
  2. 2
    화면 오른쪽 위 연결 상태 버튼(‘이 브라우저에만 저장 중’)을 눌러요.
  3. 3
    웹 앱 주소, 접속 키, 내 이름을 입력하고 [연결하기]를 눌러요.‘팀 시트 연결됨’으로 바뀌면 완료예요. 내 이름은 등록자·수정자로 표시돼요.

FAQ 등록하기

  1. 1
    오른쪽 아래 ＋ 버튼을 눌러요.
  2. 2
    분류를 고르고 질문과 답변을 입력해요.
  3. 3
    필요하면 검색어를 쉼표(,)로 구분해 넣어요.질문·답변에 없는 단어(예: 상품명, 이벤트명, 줄임말)를 넣어두면 나중에 찾기 쉬워요.
  4. 4
    오른쪽 위 [저장]을 누르면 팀 시트에 바로 저장돼요.

여러 개를 한 번에 등록할 때는 ＋ 버튼 → [여러 개 한 번에]를 고르고 아래 형식으로 붙여넣어요. 항목 사이는 빈 줄로 구분해요.

Q: 질문 내용 A: 답변 내용 K: 검색어1, 검색어2 ← 생략해도 돼요

찾기 · 복사 · 수정

  • 찾기검색창에 단어를 입력하면 질문, 답변, 검색어에서 함께 찾아요. 여러 단어는 쉼표나 띄어쓰기로 구분하면 모두 포함된 FAQ만 보여요. 위쪽 분류 카드를 누르면 해당 분류만 볼 수 있어요.
  • 정렬검색창 아래 오른쪽에서 최신 등록순, 최신 수정순, 작성자순, 질문순으로 바꿀 수 있어요. 분류별 묶음 안에서 정렬되고, 고른 정렬은 다음에 열어도 그대로예요.
  • 답변 복사각 FAQ의 [답변 복사]를 누르면 답변이 클립보드에 복사돼요. 메일이나 메신저에 바로 붙여넣을 수 있어요.
  • 수정 · 삭제각 FAQ의 ⋯ 버튼을 눌러요. 수정하면 수정자와 수정 일시가 함께 표시돼요. 다른 팀원이 먼저 고친 경우에는 최신 내용을 보여드려요.
  • 내보내기[PDF로 내보내기]는 인쇄 창에서 대상을 ‘PDF로 저장’으로 바꿔 저장해요. [DOCX로 내보내기]는 워드 파일이 바로 내려받아져요.

노출용 페이지

  • 만들기⋯ → [노출용 페이지 만들기]를 누르면 웹 앱 주소가 미리 들어간 파일이 내려받아져요. 외부에는 이 파일과 보기 전용 접속 키(VIEW_KEY)를 함께 전달해 주세요.
  • 보이는 내용노출용 페이지에서는 검색, 분류별 보기, 정렬, 답변 복사, PDF·DOCX 내보내기만 할 수 있어요. 추가·수정·삭제 버튼은 없고, 등록자·수정자 이름도 보이지 않아요.
  • 반영 시점관리페이지에서 저장하면 노출용 페이지에도 바로 반영돼요. 노출용 페이지는 5분마다, 또는 새로고침(↻)을 누르면 최신 내용을 불러와요.
